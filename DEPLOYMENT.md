# Free test deployment: Vercel + Render + Aiven MySQL

```
Browser ──► https://<project>.vercel.app  (Next.js)
               │  /api/*  is proxied (rewrite) to Render
               ▼
            https://haat-backend.onrender.com  (Express, /health)
               │  TLS, CA verified
               ▼
            Aiven MySQL 8.4 (defaultdb)
```

The browser only ever talks to the Vercel domain. The session cookie is host-only (no `Domain`), so it belongs to the Vercel
site and is sent with every `/api/*` call, and the backend's CSRF check sees the Vercel origin. This avoids the cross-site
cookie problem between `vercel.app` and `onrender.com`.

## Settings

| | Vercel (frontend) | Render (backend) |
|---|---|---|
| Root directory | repository root | `backend` |
| Install / build | default (`pnpm install`, `next build`) | `npm ci --include=dev && npm run build` |
| Start | default | `npm start` |
| Output | default (`.next`) | `dist/` |
| Health check | – | `/health` (also checks the database) |

`render.yaml` contains the Render settings; Vercel needs none.

## Environment variables

**Vercel**
- `BACKEND_API_URL` = `https://<your-service>.onrender.com` (no trailing slash). Leave `NEXT_PUBLIC_BACKEND_API_URL` **unset**.
- `NEXT_PUBLIC_SITE_URL` = `https://<project>.vercel.app` (optional, for sitemap/robots).

**Render** (see `render.yaml`)
- `FRONTEND_ORIGIN` = `https://<project>.vercel.app`, exactly as shown in the browser. Preview URLs are blocked by the CSRF check by design.
- `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD` from the Aiven console; `DB_NAME=defaultdb`, `DB_SSL=true`.
- `DB_SSL_CA_PEM` = the full text of Aiven's CA certificate (`ca.pem`). Certificate verification is always on.
- `JWT_SECRET`, `COOKIE_SECRET` are generated by the blueprint. `NODE_ENV=production`, `TRUST_PROXY=2`, `DB_POOL_SIZE=10`, `MAIL_MODE=log` are preset.
- Do **not** set `SMTP_*` (Render free blocks SMTP) or `WHATSAPP_*` until you want real messages.

## Steps

1. Review and commit your changes, then push to GitHub (`Ravi8082/Art`). Never commit `.env`, `backend/.env.aiven`, `backend/certs/` or `backups/`.
2. **Render:** New → Blueprint → select the repo → fill the `sync: false` values → create. Wait for the deploy, then open `https://<service>.onrender.com/health`; expect `{"status":"ok","database":"ok"}`.
3. **Vercel:** Add New Project → import the repo → add `BACKEND_API_URL` → Deploy. Note the project URL.
4. **Render → Environment:** set `FRONTEND_ORIGIN` to the Vercel URL and let it redeploy.
5. Check `https://<project>.vercel.app/api/events` (proxied) and the home page.
6. Test sign-in with an existing account you control. With `MAIL_MODE=log` no email is sent, so flows that need an emailed OTP cannot complete (see below).
7. Upload a file larger than 4.5 MB from the admin area to confirm the proxy accepts large bodies (see risks).

## Email and WhatsApp

- Render free blocks outbound SMTP, so the Gmail settings cannot work there. `MAIL_MODE=log` sends nothing and OTP-based flows
  (register, verify, password reset) report that the code could not be sent.
- To enable real mail later: create a Brevo account, verify a sender address, then set on Render `MAIL_MODE=brevo`,
  `BREVO_API_KEY`, `BREVO_SENDER_EMAIL` (and optionally `BREVO_SENDER_NAME`). Brevo's free plan allows about 300 emails/day.
  The key is only sent in an HTTPS header and never logged.
- WhatsApp uses the HTTPS Graph API, so it works on Render, but it is off until `WHATSAPP_TOKEN` and `WHATSAPP_PHONE_NUMBER_ID` are set.

## Known limits of the free setup

- Render free sleeps after ~15 minutes idle; the first request takes 30–60 s and the email outbox worker pauses while asleep.
- Public images in server-rendered pages load directly from the Render URL; API calls from the browser go through Vercel.
- Vercel may limit proxied request body size (documented 4.5 MB for functions). Uploads up to 50 MB are allowed by the backend. If larger uploads fail through the proxy, a custom domain with `www`/`api` subdomains (and `sameSite=lax`) is the fix.
- `TRUST_PROXY=2` assumes Vercel → Render → app. If every visitor appears to share one rate-limit bucket, adjust this value.
- Aiven allows 46 connections in total.

## Local development

Unchanged: copy `backend/.env.example` to `backend/.env`, `.env.example` to `.env.local`, and run `pnpm --dir backend dev` and `pnpm dev`.
To point the backend at Aiven locally use `DOTENV_CONFIG_PATH=.env.aiven` (see `backend/README.md`).
